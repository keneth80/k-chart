# Security Policy

## Supported Versions

Security fixes are handled on the latest released version.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability. Email the npm
package maintainer at [pretty9967@naver.com](mailto:pretty9967@naver.com) with
`[KChart Security]` in the subject line.

Send a private report to the maintainer with:

- affected version or commit
- reproduction steps
- expected and actual behavior
- impact summary

The maintainer will acknowledge the report and respond with next steps as soon
as practical. Please allow time to investigate and coordinate a fix before
publishing details.
